# LevelUpHardware

Een responsive website voor een fictief bedrijf dat computerproducten verkoopt. Dit project is ontwikkeld als onderdeel van een frontend-schoolopdracht, waarbij de bestaande website verder moest worden verbeterd op het gebied van design, gebruiksvriendelijkheid en interactie.

## Over het project

LevelUpHardware is een fictief bedrijf dat computerproducten verkoopt. Tijdens deze opdracht speelde mijn docent de rol van Daan, de opdrachtgever. Via een brief kregen we aanvullende wensen om de website naar een hoger niveau te tillen.

De belangrijkste aandachtspunten waren een betere gebruikerservaring, duidelijke navigatie, interactieve elementen en een responsive ontwerp voor zowel mobiele apparaten als desktops.

De opdrachtgever vroeg onder andere om een nieuwsbriefknop, een interactieve Google Maps-kaart, een sticky navigatiebalk en visuele feedback bij interacties met de website.

## Functionaliteiten

- Responsive ontwerp voor mobiele apparaten en desktops.
- Mobile-first ontwikkeld met CSS media queries.
- Hamburger-menu met JavaScript voor mobiele navigatie.
- Herbruikbare header en footer met PHP `require` en `include`.
- Sticky navigatiebalk die zichtbaar blijft tijdens het scrollen.
- Duidelijke knoppen en navigatielinks.
- Hover-effecten en vloeiende CSS-transities.
- Zichtbare focus-styling voor toetsenbordnavigatie.
- Nieuwsbriefknop als visueel onderdeel van de website.
- Interactieve locatiekaart met Google Maps via een iframe.

Hiermee kan ik onderdelen zoals de header en footer in aparte bestanden plaatsen en op meerdere pagina's hergebruiken. Hierdoor hoef ik dezelfde HTML-code niet steeds opnieuw te schrijven en kan ik wijzigingen gemakkelijker doorvoeren.

### Responsive design

Ik heb mobile-first gewerkt. Dit betekent dat ik de styling eerst voor kleinere schermen heb gemaakt en daarna met CSS media queries heb aangepast voor grotere schermen.

Tijdens het ontwikkelen werkte ik vaak per onderdeel aan zowel de mobiele als desktopversie.

Achteraf zou ik liever eerst de volledige mobiele versie afronden en daarna de desktopversie uitwerken. Hierdoor verwacht ik meer overzicht te houden tijdens het ontwikkelen.

### CSS en gebruikerservaring

Ik heb meer ervaring opgedaan met het verbeteren van de uitstraling en gebruiksvriendelijkheid van een website.

Hierbij heb ik gewerkt met hover-effecten, focus-styling, transities en een sticky navigatiebalk.

Ook heb ik geleerd hoe ik een footer onderaan het scherm kan houden wanneer een pagina weinig content bevat.

## Problemen en oplossingen

Een uitdaging tijdens dit project was het correct positioneren van de footer.

Wanneer een pagina weinig content bevatte, bleef er ongewenste ruimte onder de footer zichtbaar. Ik heb onderzocht hoe ik de pagina zo kon indelen dat de footer ook bij weinig content onderaan het scherm blijft staan.

Daarnaast blijft JavaScript een leerpunt. Ik kan steeds beter uitleggen wat bestaande code doet, maar vind het nog lastig om zelf te bepalen welke onderdelen ik nodig heb om een functionaliteit vanaf nul op te bouwen.
